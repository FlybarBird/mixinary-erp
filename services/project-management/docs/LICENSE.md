# GPL-3 notes (OpenProject Community)

OpenProject Community Edition is licensed under **GNU GPL v3**.

When packaging / deploying:

- [ ] Retain GPL notices for OpenProject images and derived overlays
- [ ] Do not distribute proprietary forks of OpenProject without complying with GPL-3
- [ ] Connect ERP and OpenProject only via versioned APIs / signed webhooks (no shared DB)
- [ ] Prefer company branding in the suite shell; attribute OpenProject where required
